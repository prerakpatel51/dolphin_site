Dolphin Island Tours - Docker Commands
======================================

Run all commands from the project root:

  /Users/prerak/Desktop/dolphin_site


Start / Stop
------------

Start everything in the background:

  docker compose up -d

Start and rebuild images:

  docker compose up -d --build

Stop containers without deleting data:

  docker compose stop

Stop and remove containers, keep volumes/data:

  docker compose down

Restart backend only:

  docker compose restart backend

Restart frontend only:

  docker compose restart frontend


Build / Recreate
----------------

Build all images:

  docker compose build

Build backend only:

  docker compose build backend

Build frontend only:

  docker compose build frontend

Build E2E test image only:

  docker compose build e2e

Recreate backend after backend code or .env changes:

  docker compose up -d --force-recreate backend

Recreate frontend after frontend changes:

  docker compose up -d --force-recreate frontend


Logs / Status
-------------

Show running containers:

  docker compose ps

Backend logs:

  docker compose logs -f backend

Frontend logs:

  docker compose logs -f frontend

Database logs:

  docker compose logs -f db


Backend Management
------------------

Run migrations:

  docker compose exec backend python manage.py migrate

Create admin user:

  docker compose exec backend python manage.py createsuperuser

Seed sample tours/slots:

  docker compose exec backend python manage.py seed

Open Django shell:

  docker compose exec backend python manage.py shell


Tests
-----

Backend tests:

  docker compose run --rm backend python manage.py test api --noinput --keepdb

Alternative if backend container is already running:

  docker compose exec backend python manage.py test api --noinput --keepdb

Frontend E2E tests:

  docker compose --profile test run --rm e2e

Run backend + frontend E2E test suite:

  docker compose run --rm backend python manage.py test api --noinput --keepdb
  docker compose --profile test run --rm e2e

Useful Cleanup Commands
-----------------------

Remove stopped containers and unused Docker data:

  docker system prune

WARNING: This deletes unused Docker objects. Do not run it if you are unsure.

Remove containers and volumes for this project:

  docker compose down -v

WARNING: This deletes the Postgres database volume for this project.
